# V-Lab
A desktop app that simulates laboratories virtually

## Overview

This project alleviate lack of physical laboratories in schools by providing a virtual environment for hands-on learning. The program is for students specially for student that are underserved and in under-developed areas who can't access any kind of physical laboratory or the system to carry hands-on learning (STEM-learning) at school. When I was in primary and highschool, learning was just a mere chalk-and-talk process, no curiosity, no exploration, no beyond class, boring, and retarded. School usually respond with lack of budgets, equipment or other system gaps. So in order to meet my learning gaps I started to build this app to simulate physical laboratory that doesn't need a capital, importing equipments or anything physical. This encorage every students to attend class everyday enthusiastically, to be curious and creative enough, and to enjoy the learning process overall through interactive and embeded system that allows many features to support students. This simulation app is a desktop app developed using java and its libraries on processing IDE. The project developed in a very thorough system designing and software enginering process from idea initiation, MVP to a a working simulation where students experience the intention of the project and I was be able to accept feedbacks.

## How It Works

here is how:

1. Run the setup
2. Navigate through your level of education (primary, secondary or university)
3. Do exercise and other course heavy activities through the exercise page
4. Read the experiment notes
5. Interact with simulation
6. write lab report
7. submit
8. The submission will be stored in the application data for evalution
9. Returned to homepage
